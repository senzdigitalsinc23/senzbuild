# RFC Template

## Title

Short, descriptive title of the proposed change.

## Status

- **Draft** | **Review** | **Accepted** | **Active** | **Done**

## Version

`v0.1.0` (increment with each revision)

## Date

`YYYY-MM-DD`

## Author(s)

Names and contact information

## Topic

`feature` | `improvement` | `architecture` | `deprecation` | `process`

---

## Summary

One-paragraph summary of the proposal.

## Motivation

Why is this change needed? What problem does it solve?

## Proposed Change

Detailed description of the proposed change. Include:
- API changes (if any)
- Code examples
- Configuration changes

## Backwards Compatibility

How does this affect existing code? What breaking changes are there?

## Performance Impact

What is the expected performance impact (positive or negative)?

## Security Implications

Are there any security considerations?

## Documentation

How will this be documented?

## Testing

How will this be tested?

## Alternatives Considered

What other approaches were considered and why were they rejected?

## References

Links to related issues, PRs, or external resources.
